# KAIROS dataset

Generated by `scripts/generate_dataset.sh` into `dataset/`. Every design is a validated solid with a recorded expert trajectory: the action sequence that built it, the shaped reward for each step, and the constraint report its own natural-language requirement was checked against.

## Files per design

`model.FCStd` (parametric document), `model.step` (B-rep exchange), `model.stl` (0.3 mm deflection mesh), four rendered views (`iso`, `front`, `top`, `right`), `state.json` (geometry snapshot), `requirements.json` (structured spec), and `trajectory.json` (actions, rewards, constraint report).
